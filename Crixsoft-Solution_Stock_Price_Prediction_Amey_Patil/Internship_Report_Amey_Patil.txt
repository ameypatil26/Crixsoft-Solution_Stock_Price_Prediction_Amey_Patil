# 3. Methodology

## 3.1 Data Preprocessing

The data preprocessing steps included:

1. **Data Loading:** Reading the CSV file and filtering for AAPL
2. **Date Handling:** Converting date strings to datetime format
3. **Sorting:** Ordering data chronologically
4. **Missing Values:** No missing values were found in the dataset

## 3.2 Feature Engineering

Feature engineering is the process of creating new features from raw data to improve model performance. A total of **14 features** were created:

### 3.2.1 Price-Based Features
- **Open Price:** Opening price of the day
- **High Price:** Highest price of the day
- **Low Price:** Lowest price of the day
- **Volume:** Number of shares traded

### 3.2.2 Price Ratios
- **High-Low Ratio:** `high / low` - Measures daily volatility range
- **Open-Close Ratio:** `open / close` - Indicates price movement

### 3.2.3 Moving Averages
- **5-Day Moving Average:** Short-term trend indicator
- **10-Day Moving Average:** Medium-term trend indicator
- **20-Day Moving Average:** Longer-term trend indicator

### 3.2.4 Volatility
- **20-Day Volatility:** Standard deviation of daily returns over 20 days

### 3.2.5 Advanced Technical Indicators

**RSI (Relative Strength Index):**
- Measures the speed and change of price movements
- **Scale:** 0 to 100
- **Overbought (>70):** Price may decrease
- **Oversold (<30):** Price may increase
- **Formula:** `RSI = 100 - (100 / (1 + RS))` where `RS = Average Gain / Average Loss`

**MACD (Moving Average Convergence Divergence):**
- **MACD Line:** 12-day EMA - 26-day EMA
- **Signal Line:** 9-day EMA of MACD Line
- **Histogram:** MACD Line - Signal Line
- **Interpretation:** Crossovers indicate trend changes

# 4. Machine Learning Models

## 4.1 Linear Regression

**Type:** Supervised Learning - Regression

**Description:** Linear Regression finds the best linear relationship between features and the target variable. It assumes a straight-line relationship between inputs and outputs.

**Advantages:**
- Very fast to train
- Easy to interpret and explain
- Good baseline model for comparison

**Disadvantages:**
- Cannot capture non-linear patterns
- Sensitive to outliers
- May underperform with complex data

**Mathematical Formula:**
$$y = β₀ + β₁x₁ + β₂x₂ + ... + βₙxₙ$$

## 4.2 Random Forest

**Type:** Ensemble Learning - Regression

**Description:** Random Forest builds multiple decision trees and combines their predictions through averaging. Each tree is trained on a random subset of the data.

**Advantages:**
- Can capture complex non-linear relationships
- Provides feature importance scores
- Less prone to overfitting
- Handles both numerical and categorical features

**Disadvantages:**
- Slower to train than Linear Regression
- More complex to interpret
- Requires more memory

**Hyperparameters Used:**
- `n_estimators`: 100 trees
- `max_depth`: 10 levels
- `min_samples_split`: 5 samples


# 5. Model Training Process

## 5.1 Training Pipeline

The model training process followed these steps:

1. **Data Loading:** Load the S&P 500 dataset
2. **Feature Engineering:** Create 14 technical features
3. **Feature Scaling:** Scale all features to [0, 1] range
4. **Data Split:** 80% training, 20% testing (chronological)
5. **Model Training:** Train both models on training data
6. **Model Evaluation:** Test on unseen data
7. **Results Comparison:** Compare performance metrics

## 5.2 Data Split Strategy

**Why Chronological Split Matters:**
- Stock data is time-series data
- Future data should NOT influence past predictions
- Random split would cause "look-ahead bias"
- Chronological split maintains temporal order

**Split Details:**
- **Training Set:** 80% of data (earlier dates)
- **Testing Set:** 20% of data (later dates)
- **No Shuffling:** Data kept in chronological order

## 5.3 Feature Scaling

All features were scaled to the range [0, 1] using MinMaxScaler:

$$X_{scaled} = \frac{X - X_{min}}{X_{max} - X_{min}}$$

**Why Scaling is Important:**
- Features have different units (price, volume, ratios)
- Models perform better with normalized data
- Prevents features with larger values from dominating

## 5.4 Model Training

### Linear Regression Training:
- Method: Ordinary Least Squares
- Objective: Minimize sum of squared errors
- No hyperparameters to tune

### Random Forest Training:
- **n_estimators:** 100 trees
- **max_depth:** 10 levels
- **min_samples_split:** 5 samples
- **n_jobs:** -1 (use all CPU cores)

# 6. Evaluation Metrics

## 6.1 RMSE (Root Mean Square Error)

**Definition:** Measures the average prediction error, giving more weight to large errors.

**Formula:** $$RMSE = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2}$$

**Interpretation:** The model's predictions are off by $X on average.

**Goal:** Lower is better.

## 6.2 MAE (Mean Absolute Error)

**Definition:** Measures the average absolute difference between predictions and actual values.

**Formula:** $$MAE = \frac{1}{n}\sum_{i=1}^{n}|y_i - \hat{y}_i|$$

**Interpretation:** The average absolute error is $X.

**Goal:** Lower is better.

## 6.3 Directional Accuracy

**Definition:** Measures how often the model correctly predicts the direction of price movement (up or down).

**Formula:** $$\text{Directional Accuracy} = \frac{\text{Correct Direction Predictions}}{\text{Total Predictions}} \times 100\%$$

**Interpretation:** The model correctly predicted price direction X% of the time.

**Goal:** Higher is better (above 50% is better than random guessing).

# 9. Challenges and Limitations

## 9.1 Technical Challenges

1. **Time-Series Nature:**
   - Stock prices are sequential and autocorrelated
   - Cannot use random split like other ML problems
   - Requires careful validation strategy

2. **Non-Linearity:**
   - Price movements are not linear
   - Simple models struggle with complex patterns
   - Requires advanced models for better performance

3. **Market Noise:**
   - Random events affect stock prices
   - News, sentiment, and economic factors not included
   - Models cannot predict unpredictable events

## 9.2 Data Limitations

1. **Limited Timeframe:** Only 5 years of historical data
2. **Single Stock Focus:** Only AAPL was analyzed
3. **No External Data:** Missing news, economic indicators, or sentiment
4. **Data Sourcing:** Data may have gaps or errors

## 9.3 Model Limitations

1. **No Real-Time Testing:** Models not tested in live market
2. **No Trading Strategy:** Predictions not integrated with trading decisions
3. **Overfitting Risk:** Models may not generalize to future data
4. **No Risk Management:** Models don't account for risk factors
